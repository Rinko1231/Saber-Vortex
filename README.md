# Saber Vortex · 光刃涡旋

一款二次元风格的浏览器肉鸽生存 Demo。角色固定在涡心，不能移动；玩家用鼠标、触屏或相对鼠标输入控制武器，围绕角色 360° 旋转、伸缩，并在两分钟内选择强化、击败敌人。

## 直接试玩

```powershell
npm install
npm run dev
```

打开终端显示的地址，通常是 `http://localhost:5173/`。

## 操作

- 桌面端开始战斗后自动锁定鼠标。即使指针离开画布、越过状态栏或到达窗口边缘，仍会通过相对移动控制武器。
- 移动鼠标 / 拖动触屏：控制武器方向和伸缩距离。
- 快速挥动：产生切向速度，形成斩击。
- 快速伸缩：产生轴向速度，形成刺击。
- 武器静止贴住敌人不会掉血。
- `Space`：释放角色主动技能。
- `Esc` / `P`：解锁鼠标并暂停。
- `1` / `2` / `3`：升级时快速选择。
- 标题页和角色页可切换“自动 / 横屏 / 竖屏”显示模式。

当前 Demo 一局 120 秒。85 秒时虚空女帝降临；击杀女帝或撑到倒计时结束即可获胜。

## 伤害模型

接触点速度拆成两轴：

- 切向速度 = 角速度 × 接触半径。
- 轴向速度 = 武器伸缩速度。
- 两轴合成总速度，低于角色最低斩击速度时不造成伤害。
- 伤害按两轴占比与角色斩击/刺击系数混合计算。

因此阿罗芒的刺击、北堂雪的扫击、袖锋的末端伤害和光剑的剑气，都能建立在同一套速度规则上。

- 六角色选择页、占位立绘、Q 版游戏内占位小人。
- 六种武器判定与六套主动技能。
- 通用强化 + 每名角色 4–5 条专属强化。

- 特殊敌人词缀：孵裂、殉爆、斩击易伤、刺击易伤、滞刃、侧盾。
- 减速场有下限，敌人移动速度保底 22，不会完全冻结。
- 桌面鼠标锁定、触屏输入、横屏 1280×720 与竖屏 720×1280 战场。
- 完整标题、角色选择、HUD、技能冷却、升级、暂停、失败、胜利和重开。

## 构建

```powershell
npm run build
npm run preview
```

构建产物在 `dist/`。Vite 使用相对路径基址，可部署到任意 GitHub Pages 仓库子路径。

## 部署到 GitHub Pages

1. 推送到 `main` 分支。
2. 仓库进入 `Settings → Pages`，`Source` 选择 `GitHub Actions`。
3. `.github/workflows/deploy.yml` 会构建并发布 `dist/`。

## 项目结构

```text
src/
  game/characters.ts     # 六名角色、武器类型、基础数值与专属路线
  game/simulation.ts     # 速度分解、战斗、敌人词缀、技能、强化、Boss
  phaser/BootScene.ts    # SVG 资源加载与角色占位纹理生成
  phaser/GameScene.ts    # 武器绘制、投射物、特效、鼠标锁定、输入适配
  ui/UI.ts               # 角色选择、HUD、技能、升级、显示模式
  style.css              # 桌面与竖屏界面
scripts/playtest.mjs     # 浏览器自动试玩
public/assets/           # SVG 占位角色、敌人、灵魂
```

## 自动试玩

先启动开发服务器，再开另一个终端：

```powershell
npm run playtest
```

脚本会检查角色选择、360° 角度、剑长变化、静止不造成伤害、移动命中、剑气、升级专属卡、主动技能、暂停、五名其余角色启动、阿罗芒连刺、北堂雪弹反、特殊敌人词缀、竖屏布局和鼠标锁定，并把截图写入 `artifacts/`。
